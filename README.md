# TIMO — Task & Interaction Management Organizer
### Neubrutalism Edition · Kelompok 02 RPL · UIN Sunan Gunung Djati Bandung

TIMO adalah aplikasi web manajemen tugas kuliah berbasis Next.js yang dikembangkan khusus untuk mahasiswa guna mengorganisasi tugas secara terstruktur, rapi, dan estetis. Proyek ini mengusung tema **Neubrutalism** dengan karakteristik visual yang khas: warna-warna saturasi tinggi (bold), garis tepi (border) tebal, sudut tajam, dan bayangan tegas tanpa efek blur (hard offset shadow).

---

## 🚀 Fitur Utama

1. **Dashboard Utama**:
   - Kartu statistik tugas: menampilkan jumlah tugas baru (Todo), tugas aktif (In Progress), dan tugas selesai (Done).
   - Daftar tugas (Task Grid) bergaya kartu Neubrutalism dengan transisi efek hover dan tekan mikro-animasi.
   - Pilihan mata kuliah dinamis dengan skema warna yang dihasilkan secara otomatis dan deterministik dari judul mata kuliah.
2. **Sistem Autentikasi Mandiri**:
   - Halaman Login & Registrasi dengan desain split-screen adaptif.
   - Manajemen sesi aman menggunakan token cookie berbasis Supabase Database.
3. **Manajemen Tugas Lengkap (CRUD)**:
   - Tambah tugas baru melalui modal dialog interaktif dengan validasi input yang aman.
   - Edit detail tugas (mengubah judul, deskripsi, mata kuliah, deadline, prioritas, atau status).
   - Hapus tugas dengan konfirmasi dialog.
4. **Filter & Sortir Cerdas**:
   - Filter tugas berdasarkan Status (Semua, Belum Dimulai, Sedang Dikerjakan, Selesai).
   - Filter tugas berdasarkan Tingkat Prioritas (Semua, Tinggi, Sedang, Rendah).
   - Cari tugas berdasarkan Mata Kuliah.
   - Urutkan tugas berdasarkan Tenggat Waktu (Deadline) terdekat atau tingkat prioritas.
5. **Halaman Profil Pengguna**:
   - Ringkasan statistik akun mahasiswa.
   - Progress bar pengerjaan tugas visual yang interaktif.
   - Menu keluar (Logout) yang aman dengan pembersihan sesi.

## 💾 Persiapan Database (Supabase)

Sebelum menjalankan aplikasi, Anda perlu menyiapkan tabel-tabel di project Supabase Anda. Gunakan perintah SQL di bawah ini di bagian **SQL Editor** pada dashboard Supabase Anda:

```sql
-- 1. Tabel users
CREATE TABLE IF NOT EXISTS users (
  id BIGINT GENERATED BY DEFAULT AS IDENTITY PRIMARY KEY,
  username VARCHAR(255) NOT NULL,
  email VARCHAR(255) UNIQUE NOT NULL,
  password VARCHAR(255) NOT NULL,
  role VARCHAR(50) DEFAULT 'user',
  created_at TIMESTAMPTZ DEFAULT NOW(),
  updated_at TIMESTAMPTZ DEFAULT NOW()
);

-- 2. Tabel sessions (untuk manajemen session cookie)
CREATE TABLE IF NOT EXISTS sessions (
  id BIGINT GENERATED BY DEFAULT AS IDENTITY PRIMARY KEY,
  token VARCHAR(255) UNIQUE NOT NULL,
  user_id BIGINT REFERENCES users(id) ON DELETE CASCADE,
  created_at TIMESTAMPTZ DEFAULT NOW(),
  updated_at TIMESTAMPTZ DEFAULT NOW()
);

-- 3. Tabel tasks
CREATE TABLE IF NOT EXISTS tasks (
  id BIGINT GENERATED BY DEFAULT AS IDENTITY PRIMARY KEY,
  user_id BIGINT REFERENCES users(id) ON DELETE CASCADE,
  title VARCHAR(255) NOT NULL,
  description TEXT DEFAULT '',
  subject VARCHAR(255) NOT NULL,
  priority VARCHAR(50) DEFAULT 'medium', -- low, medium, high
  status VARCHAR(50) DEFAULT 'todo', -- todo, inprogress, done
  deadline DATE NOT NULL,
  created_at TIMESTAMPTZ DEFAULT NOW(),
  updated_at TIMESTAMPTZ DEFAULT NOW()
);
```

## ⚙️ Cara Menjalankan Aplikasi

### 1. Prasyarat
Pastikan Anda sudah menginstal:
- [Git](https://git-scm.com/)
- [Bun](https://bun.sh/) (Disarankan) atau [Node.js](https://nodejs.org/) (v20 ke atas)

### 2. Kloning Repositori
```bash
git clone https://github.com/rifqymuhamad10/second-TIMO-app.git
cd second-TIMO-app
```

### 3. Instalasi Dependensi
Gunakan Bun untuk menginstal modul dependensi:
```bash
bun install
```
*(Atau `npm install` jika menggunakan Node.js)*

### 4. Konfigurasi Environment Variables
Buat file bernama `.env.local` di direktori utama (root) proyek Anda dan isi dengan API URL dan Anonymous Key dari proyek Supabase Anda:

```env
NEXT_PUBLIC_SUPABASE_URL=https://<your-supabase-project-id>.supabase.co
NEXT_PUBLIC_SUPABASE_ANON_KEY=<your-supabase-anon-key>
```

### 5. Jalankan Development Server
Jalankan server lokal:
```bash
bun run dev
```
*(Atau `npm run dev`)*

Buka [http://localhost:3000](http://localhost:3000) melalui browser Anda untuk melihat hasilnya.

### 6. Build untuk Produksi
Untuk melakukan kompilasi proyek menjadi versi produksi siap rilis:
```bash
bun run build
```
Untuk menjalankan versi produksi tersebut di server lokal:
```bash
bun run start
```

## 📚 Panduan Desain Neubrutalism (Pedoman Teknis)
Desain Neubrutalism aplikasi ini diatur di [globals.css](file:///d:/Tugas/semester%204/TIMO%20web%20V2/src/app/globals.css) menggunakan beberapa token aturan penting:
- **Ketebalan Border**: `3px solid #1A1A1A` (`border-nb`)
- **Efek Bayangan**: `4px 4px 0px #1A1A1A` (`shadow-nb`)
- **Tingkat Lengkungan**: `0px` atau maks `4px`
- **Warna Kontras Tinggi**: Kuning (`#FFEB3B`), Merah (`#FF5252`), Biru (`#2196F3`), Hijau (`#69F0AE`), latar belakang Off-white (`#FFFDF0`), dan warna tulisan Off-black (`#1A1A1A`).
- **Mikro-interaksi**: Hover bertransisi bergeser ke atas `translateY(-2px)` dengan shadow membesar, dan saat ditekan/aktif bergeser ke bawah `translateY(2px)` dengan shadow mengecil.
